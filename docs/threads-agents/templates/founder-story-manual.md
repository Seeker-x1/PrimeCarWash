# ストーリー投稿（オーナー手動専用）

`founder-story` テーマ。**自動バンク・Cron には含めない。** Threads アプリから直接投稿。

## 方針（合意済み）

- 静か・上質なトーン（プレミアムブランド）
- **接客のキビキビ感・ニコニコ感は文章に書かない** → 動画・写真で見せる
- **紹介のお願いは書かない**
- 実話のみ。盛らない

## 週1〜2本でよいネタ

| 型 | 例 |
|----|-----|
| なぜ始めたか | 出張洗車にした理由（1エピソード） |
| 1台との向き合い | その日の判断・迷い・こだわり |
| ビフォーアフター | 30秒動画 + 短文キャプション |
| 失敗と学び | 過去のミス → いまの基準に変えたこと |
| 葛藤 | 時間・品質・距離のバランス（ありのまま） |

## キャプション雛形

```
（フック：1行・問いか断言）

（事実：何が起きたか、3〜5行）

（学び or いまの基準：1〜2行）

（質問で締め：1行）
```

## 撮影メモ（動画向き）

- 顔出し任意。手元・車・光の当たり方でも可
- ナンバー・表札は映さない
- 暗め・高級感。派手なBGM不要

## エージェントの使い方

```
@threads-field-storyteller 今日の施工メモ: … → キャプション案
@threads-content-director founder-story 用に下書き（事実: …）
```

投稿ボタンを押すのはオーナーのみ。
